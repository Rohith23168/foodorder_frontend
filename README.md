# 🍔 Online Food Ordering System

A full-stack food ordering platform that allows users to browse restaurants, explore menus, add food items to a shopping cart, place orders, and track their order status. The application also includes secure user authentication and an admin dashboard for managing restaurants, menus, and orders.

---

## 🚀 Features

### 👤 User Features

- User Registration & Login
- Secure Authentication
- Browse Restaurants
- View Restaurant Menus
- Search Food Items
- Add/Remove Items from Cart
- Update Cart Quantity
- Checkout Process
- Place Orders
- View Order History
- Track Order Status

### 👨‍💼 Admin Features

- Manage Restaurants
- Manage Food Categories
- Add/Edit/Delete Food Items
- Manage Customer Orders
- Update Order Status
- View Registered Users

## 📌 Project Workflow

1. User registers or logs in.
2. Browse available restaurants.
3. Select a restaurant and view its menu.
4. Add food items to the shopping cart.
5. Proceed to checkout.
6. Place the order.
7. View order history and track order status.
8. Admin manages restaurants, menus, and customer orders.

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/Rohithrgowda23/foodorder_frontend.git
```

### Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```
